# 🛠️ 脚本工具文件夹说明

## 📁 文件夹结构

```
scripts/
├── env_setup/           # 环境配置工具
│   ├── ml-full/         # 机器学习环境
│   │   └── 环境检查.py   # 环境验证脚本
│   ├── cv-yolo/         # 机器视觉环境
│   │   └── 环境检查.py   # 环境验证脚本
│   ├── mp/              # MediaPipe环境
│   │   └── 环境检查.py   # 环境验证脚本
│   └── 一键安装.py       # 一键安装所有环境
└── utils/               # 通用工具
    └── 摄像头测试.py     # 摄像头测试工具
```

## 🚀 使用指南

### 1. 一键安装所有环境

```bash
cd ML-DL-CV-Lab
python scripts/env_setup/一键安装.py
```

### 2. 验证环境安装

```bash
# 验证机器学习环境
conda activate ml-full
python scripts/env_setup/ml-full/环境检查.py

# 验证机器视觉环境
conda activate cv-yolo
python scripts/env_setup/cv-yolo/环境检查.py

# 验证MediaPipe环境
conda activate mp
python scripts/env_setup/mp/环境检查.py
```

### 3. 运行摄像头测试

```bash
python scripts/utils/摄像头测试.py
```

## 📋 环境说明

| 环境名称 | 用途 | 主要依赖 |
|---------|------|---------|
| **ml-full** | 机器学习全栈学习 | NumPy, Pandas, scikit-learn, Matplotlib |
| **cv-yolo** | 机器视觉YOLO实战 | PyTorch, Ultralytics YOLO, OpenCV |
| **mp** | MediaPipe姿态估计 | MediaPipe, OpenCV |

## 💡 使用建议

1. **首次安装**：运行 `一键安装.py` 创建所有环境
2. **日常使用**：使用 `conda activate <环境名>` 切换环境
3. **环境验证**：定期运行对应环境的检查脚本
4. **问题排查**：如果遇到依赖问题，先运行检查脚本确认环境状态
