# 🛠️ 脚本工具文件夹说明

## 📁 文件夹结构

```
scripts/
├── env_setup/           # 环境配置工具
│   ├── 环境检查.py       # main统一环境验证脚本
│   └── 一键安装.py       # 一键创建main统一环境
└── utils/               # 通用工具
    └── 摄像头测试.py     # 摄像头测试工具
```

## 🚀 使用指南

### 1. 一键安装统一环境

```bash
cd ML-DL-CV-Lab
python scripts/env_setup/一键安装.py
```

或直接使用仓库根目录的 `environment.yml`：

```bash
conda env create -f environment.yml
conda activate main
```

### 2. 验证环境安装

```bash
conda activate main
python scripts/env_setup/环境检查.py
```

### 3. 运行摄像头测试

```bash
python scripts/utils/摄像头测试.py
```

## 📋 环境说明

| 环境名称 | 用途 | 主要依赖 |
|---------|------|---------|
| **main** | 全栈统一学习环境 | NumPy, Pandas, scikit-learn, PyTorch, Ultralytics YOLO, OpenCV, MediaPipe |

学习阶段统一使用 `main` 环境，覆盖机器学习、深度学习、机器视觉YOLO、MediaPipe姿态估计全部内容。若后续因项目部署或严重依赖冲突需拆分环境，届时再按需隔离。

## 💡 使用建议

1. **首次安装**：运行 `一键安装.py` 或 `conda env create -f environment.yml`
2. **日常使用**：`conda activate main` 即可开始任意阶段的学习
3. **环境验证**：运行 `环境检查.py` 确认依赖完整
4. **问题排查**：遇到依赖问题，先运行检查脚本确认环境状态
