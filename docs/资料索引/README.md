# 资料索引（可交互 HTML）

本目录集中存放**用浏览器打开的离线单文件 HTML**。它们与 `.md` 笔记分开放，有两个理由：

1. **打开方式不同** —— md 在编辑器里读；这些页面双击用浏览器打开，带样式、页内跳转、可打印
2. **职责不同** —— 这些页面做的是「资料定位与可视化」，md 做的是「文字笔记」

**规则：仓库内所有 HTML 一律放这里，主题目录只留 md / py。** 该规则已写入根 `README.md` 的「文件使用规范」。

## 跳转机制与迁移注意

页面里指向书本 / PDF 的链接使用 **`file:///E:/...` 绝对路径**（URL 编码），所以：

- ✅ 页面本身挪位置**不会断链**
- ⚠️ 换机器、或本地 PDF 目录改名后会失效，需**重新生成**而不能只拷 HTML
