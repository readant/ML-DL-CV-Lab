# 文献管理 (literature/)

按研究主题分子文件夹，例如 `literature/01_注意力机制/`。

## 每个主题文件夹建议包含

- `文献清单.md` 或 `.csv`：题名 / 作者 / 单位 / 年份 / venue / DOI / 关键词
- `文献笔记.md`：**批判性笔记**（不是摘要抄写），每篇回答四个问题：
  1. 解决什么问题？
  2. 方法核心是什么？
  3. 局限 / 未解决问题？
  4. 与我的研究有何关联？
- 结构化题录统一汇总到根 `references.bib`（BibTeX），便于引用。

## 检索与选文

- 工具：Papers with Code（代码+论文绑定）、arXiv、Google Scholar、Semantic Scholar、知网(CNKI)。
- 选文标准：顶会/顶刊（CVPR / ICLR / NeurIPS / ICML 等）、引用数、是否有官方实现。
- 先读综述（survey）锁定脉络，再读原始论文。
