# 注意力机制（Attention / Multi-Head Attention）

从零实现「注意力」与「多头注意力」，并用 14 条断言验证那些容易被含糊带过的设计细节。

不依赖任何预训练权重、不需要 GPU、不需要训练 —— 全部可在几秒内跑完。

## 目录

```plaintext
01_注意力机制/
├── README.md               # 本说明
├── attention_numpy.py      # 纯 NumPy 从零实现（softmax / 缩放点积 / 多头 / 因果掩码 / 位置编码）
├── attention_torch.py      # PyTorch nn.Module 实现（可训练，含 TransformerBlock）
├── test_attention.py       # 14 条断言
├── demo_attention.py       # 权重矩阵字符热力图演示
└── 注意力实现笔记.html      # 阅读页：数据流、结论、原始输出、源码全文
```

配套笔记在 [`../../00_笔记/01_注意力机制/`](../../00_笔记/01_注意力机制/)。

## 环境与运行

```bash
conda activate main
cd 02_deep_learning/01_代码/01_注意力机制

python -m unittest test_attention -v   # 期望：Ran 14 tests ... OK
python demo_attention.py               # 看权重矩阵
```

也可以在仓库根目录直接发现测试（脚本内已做路径处理，不依赖工作目录）：

```bash
python -m unittest discover -s "02_deep_learning/01_代码/01_注意力机制" -p "test_*.py" -v
```

依赖：`numpy` 必需，`torch` 可选。没装 torch 时 PyTorch 那 6 条断言会自动跳过，报告 `OK (skipped=6)`。

## 形状约定

| 阶段 | 形状 |
| :--- | :--- |
| 输入 `x` | `(B, T, d)` |
| 线性投影 `Q/K/V` | `(B, T, d)` |
| 分头 | `(B, h, T, dk)`，`dk = d / h` |
| 分数 `QKᵀ/√dk` | `(B, h, T, S)` |
| 权重（softmax 后） | `(B, h, T, S)`，每行和为 1 |
| 输出 | `(B, T, d)` |

## 14 条断言在验证什么

| # | 断言 | 否定的错误做法 / 澄清的事实 |
| :-- | :--- | :--- |
| 1 | 权重每行和为 1 | — |
| 2 | 因果掩码后未来位置权重恰为 0 | 只是「很小」不算对 |
| 3 | 先 softmax 再乘 mask，剩余权重和 < 1 | **mask 必须加在 softmax 之前** |
| 4 | 参数量 = 4d²，与头数无关 | 「多头 = 参数变 h 倍」是误解 |
| 5 | `h=1` 时与手写单头逐位相等 | 多头是单头的推广 |
| 6 | 无位置编码时自注意力对置换等变 | 打乱词序，输出只是跟着重排 |
| 7 | 加位置编码后该等变性被破坏 | 位置编码存在的理由 |
| 8 | NumPy 版与 PyTorch 版逐位一致 | 两份实现互相校验 |
| 9 | 与 `F.scaled_dot_product_attention` 一致 | 与工业实现对齐 |
| 10 | 梯度存在且有限 | 能训练 |
| 11 | 掩码同时切断对未来位置的梯度 | 只置零权重不够 |
| 12 | 交叉注意力 `(B,T,d)×(B,S,d) → (B,h,T,S)` | Q 与 KV 长度可不同 |
| 13 | `TransformerBlock` 输出形状不变 | 注意力只是块里两个子层之一 |
| 14 | softmax 对 1e4 量级输入不出 nan | 数值稳定性 |

## demo 演示什么

1. **形状与归一化**：`(1,11,16)` 输入 → `(1,4,11,11)` 权重，行和恒为 1，参数量 1024 = 4×16²
2. **因果掩码**：第一个词只能看自己 → 权重必然是 `1.000`
3. **为什么 `W_q` 和 `W_k` 必须分开**：绑定时分数矩阵对称，**91%** 的词最强关注自己、对角线平均权重 **0.498**；换成两个独立矩阵后降到 **9%** 和 **0.088**
4. **多头**：4 个头的关注对象与分布熵不同（随机初始化，差异是噪声；训练后才分化）

## 边界

- **不含训练**：没有数据集、loss、梯度更新。要跑训练去看《从零构建大语言模型》第 3–4 章。
- **不含 FlashAttention / 稀疏注意力 / 线性注意力**：只保留标准实现，便于和公式逐行对照。
- **demo 用随机权重**：不演示「it 指向 animal」这类语义现象 —— 那需要训练好的权重，手写不出来。只在能用随机初始化验证的地方下结论。
