# A5 条件调制（FiLM）

> **一句话**：用一路信息的输出，生成"缩放系数 + 平移量"，去调整另一路信息。

| 属性 | 值 |
| :--- | :--- |
| 来源 | Perez et al. *FiLM: Visual Reasoning with a General Conditioning Layer*. AAAI 2018 |
| 作用粒度 | 按特征列，但**由外部输入决定** |
| 参数量 | 约 `2·C·d_cond`（通常极小） |
| 实现长度 | 约 10 行 |
| 恒等起点 | ✅ 容易做到（见第 4 节） |

---

## 1. 解决什么问题

**痛点**：你有两类信息，一类是"主特征"（要处理的东西），一类是"条件/上下文"（决定怎么处理）。朴素做法是把两者拼接后一起送进网络，但这要求网络自己学会"条件该怎么影响主特征"，很难学到。

FiLM 直接把这个关系写进结构：**条件负责生成参数，主特征负责被调整。**

典型场景：给模型一个"工况"向量，让它据此调整对传感器特征的处理强度。

## 2. 机制（不用公式）

两个小线性层，把条件向量映射成两个和主特征**同长度**的向量：

- `γ`（gamma，缩放）：初始全 1
- `β`（beta，平移）：初始全 0

然后作用到主特征上：**新特征 = γ × 主特征 + β**。

和 SE（A1）的差别，一句话说清：

| | 门控信号来自 | 操作 |
| :--- | :--- | :--- |
| SE | 主特征**自己** | 只缩放 |
| FiLM | **另一路**输入 | 缩放 + 平移 |

所以 SE 是"自我评估"，FiLM 是"外部指令"。多出来的平移项让 FiLM 能改变特征的基准位置，表达力比纯缩放强。

## 3. 形状怎么变

| 张量 | 形状 | 说明 |
| :--- | :--- | :--- |
| 主特征 `x` | `[B, C]` | 要被调整的东西 |
| 条件 `cond` | `[B, d]` | 决定怎么调整，d 可以和 C 完全无关 |
| `γ` | `[B, C]` | 由 `cond` 线性变换得到 |
| `β` | `[B, C]` | 同上 |
| 输出 | `[B, C]` | 与 `x` 同形状 |

关键：**形状不变**，所以能插在任何一层后面，上下游都不用改。

## 4. 最小实现

完整可跑版（含恒等性与「破坏恒等」演示、11 条测试）在 [`../../01_代码/06_条件调制_FiLM/`](../../01_代码/06_条件调制_FiLM/)。下面摘录核心部分：

```python
import torch
import torch.nn as nn

class FiLM(nn.Module):
    """用 cond 调制 x。x: [B, C]，cond: [B, d]，输出 [B, C]。"""

    def __init__(self, cond_dim, n_features):
        super().__init__()
        self.to_gamma = nn.Linear(cond_dim, n_features)
        self.to_beta = nn.Linear(cond_dim, n_features)
        # 恒等初始化：γ≡1、β≡0，加进去的当步不改变网络行为
        nn.init.zeros_(self.to_gamma.weight)
        nn.init.ones_(self.to_gamma.bias)
        nn.init.zeros_(self.to_beta.weight)
        nn.init.zeros_(self.to_beta.bias)

    def forward(self, x, cond):
        gamma = self.to_gamma(cond)      # [B, C]
        beta = self.to_beta(cond)        # [B, C]
        return gamma * x + beta


if __name__ == "__main__":
    x = torch.randn(4, 16)
    cond = torch.randn(4, 5)
    film = FiLM(5, 16)
    out = film(x, cond)
    print("输出形状:", tuple(out.shape))
    print("是否恒等:", torch.allclose(out, x))
    print("参数量:", sum(p.numel() for p in film.parameters()))  # 2*(5*16+16) = 192
```

跑一遍应该看到 `True` —— 初始状态下输出和输入**逐元素相等**。

**动手验证理解**：把 `nn.init.ones_(self.to_gamma.bias)` 改成 `nn.init.zeros_`，再跑，恒等就变成 `False`，输出全被压成 0。这一步能让你看清"恒等起点是靠初始化造出来的，不是结构自带的"。

## 5. 变体与对比

| 变体 | 差别 | 什么时候用 |
| :--- | :--- | :--- |
| **FiLM**（本文） | 缩放 + 平移，条件来自外部 | 两路信息，一路是上下文 |
| **SE**（A1） | 只有缩放，条件来自自身 | 只有一路输入 |
| **交叉注意力**（A4） | 主特征和条件做逐元素加权组合 | 条件需要"挑选"主特征的某些部分 |
| **AdaIN** | 用条件控制归一化的均值方差 | 图像风格迁移，本质是 FiLM 的特例 |

**与交叉注意力的取舍**：FiLM 是"全局指令"——条件只决定"这一列整体放大还是缩小"，不看具体样本内容。交叉注意力是"精细检索"——能针对每个条件元素去匹配主特征的不同部分。前者参数少 1~2 个数量级，多数情况下够用。

## 6. 何时用 / 何时别用

**用**：
- 两路异构输入，其中一路是"工况/上下文/任务标识"，另一路是主特征
- 想让条件影响主特征的处理强度，但不想背一个注意力的复杂度
- 需要干净的对照实验 —— FiLM 的恒等初始化是**结构+初始化**共同保证的，比 SE 好控制

**别用**：
- 只有一路输入 —— 那是 SE 的活
- 条件需要和主特征的**不同部分**分别交互（比如条件有 5 个元素，要分别去匹配 5 组特征）—— 那是交叉注意力的活
- 条件维度远大于主特征维度时，`2·C·d_cond` 的参数量会反超主网络，需要先估一下
