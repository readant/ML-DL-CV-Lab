## 各自怎么用

**技术点索引** —— 页码来自 PDF 内置书签（`get_toc`），并逐条回到正文里搜标题做过 ±2 页校验（106 条中 105 条原页正确、1 条修正、0 条未定位）。点章节名会直接打开对应 PDF 并跳到那一页。

**中文文献清单** —— 知网「篇名重检」链接不依赖会话 token，长期有效。注意：**知网结果顺序会变**，同一链接两次打开首条可能不同，请在结果列表里按题名核对，不要点第一条就走。

**文献笔记** —— 每条都做了三件事：用详情页真实摘要核对文献身份、把摘要压成 3–4 个可判断要点、标出对本方向（物联网 / 时序）的用途。摘要原文折叠在卡片下方，可展开比对。

## 关键结论

1. 中文文献对注意力的定义高度一致，但都停在「动态权重」这一层，不涉及 Q/K/V 的不对称性与 √d_k 的作用。
2. 「多头」在中文论文里普遍是**增强模块**而非研究对象 —— 7 篇里没有一篇给头数、没有单头对照。
3. 最值得借鉴的不是结论，是实验设计：特征消融 + 模型对比 + 多时间尺度。
