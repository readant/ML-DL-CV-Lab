# 神经网络从零实现（笔记）

对应的可运行代码在 [`../../01_代码/02_神经网络从零实现_NNDL/`](../../01_代码/02_神经网络从零实现_NNDL/)。

## 这个模块解决什么

用最朴素的方式把「一个三层全连接网络如何完成分类」走通：参数化映射 + 交叉熵损失 +
SGD（带动量）优化。它是深度学习基础层的「最小可运行范例」，与注意力机制同属
「从零实现 + 断言钉死」的方法论。

## 关键知识点

- **前向**：`Flatten → Linear(784,30) → Linear(30,10) → log_softmax`。
- **损失**：`CrossEntropyLoss` 实际是 `log_softmax + NLLLoss`，输出层用 `log_softmax`
  而非 `softmax` 是为了数值稳定地与 `NLLLoss` 配合。
- **反向**：PyTorch 的 `autograd` 自动求导；`loss.backward()` 后各参数 `.grad` 非零即说明
  梯度链路通畅（见测试断言 5）。
- **优化**：`SGD(lr=0.001, momentum=0.9)`，动量加速并抑制震荡。
- **参数量**：两层 Linear 含偏置，共 `(784·30+30)+(30·10+10)=23860` 个参数（见断言 4）。

## 批判性笔记（四问法）

1. **这篇/这段代码解决什么问题**：用一个可端到端训练的小网络，讲清「数据→损失→梯度→
   更新」的最简闭环，是理解一切复杂网络的起点。
2. **方法**：全连接 + 交叉熵 + SGD；无卷积、无正则、无注意力——刻意保持最小。
3. **局限**：全连接对图像像素扁平化处理，参数随输入维度线性膨胀、丢空间结构；
   这也是后续 CNN 要解决的痛点。
4. **与我的研究有何关联**：作为基础层方法底座，任何上层结构（CNN/RNN/Transformer）
   的训练闭环本质相同；先在此把「损失确实在下降」钉死，再往上加结构才有对照基线。
