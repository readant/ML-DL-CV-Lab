## 什么是机器学习

Machine Learning 机器学习

让电脑自己从数据里面找规律。

**机器学习 = 大量数据 + 强大算例 + 不断试错**
它就是一个高级统计工具，并没有多玄乎。

*机器学习不是把规则写死给机器，而是让机器从历史数据中自动拟合出一个映射函数，用来预测未知数据，说白了，就是让电脑自己找规律。*

## 什么是深度学习

Deep Learning 深度学习

也叫深度神经网络，**大脑仿生**，设计一层一层的神经元模拟万事万物。

*深度学习是机器学习的一个子集，它的核心是多层神经网络自动完成“特征提取”，而传统机器学习需要人工手动设计特征。简单说传统ML是“你叫它看什么”，深度学习是“它自己学会该看什么”。*
